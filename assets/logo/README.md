# Logo

The mark is a "G" with nodes and circuit lines. All files have a transparent background.

| File | Use |
| --- | --- |
| `logo-on-dark-1024.png`, `logo-on-dark-512.png` | Dark backgrounds. Lime `#94C423` with lighter nodes `#C2F670`. |
| `logo-on-light-1024.png`, `logo-on-light-512.png` | Light backgrounds. Darker greens (`#3F6212`, `#4D7C0F`) for enough contrast on white. |
| `icon-512.png`, `apple-touch-icon.png` (180), `favicon.ico` (16, 32, 48) | Browser tab and home screen. |

The flat shapes were extracted from the original artwork, the glow and the background were
removed, and the result was cropped to a square with a small margin.
